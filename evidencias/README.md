# Evidencias de ejecución

Salidas de la ejecución de las pruebas, una por fecha. Se generan con:

```bash
make evidencia          # Linux o macOS
.\make.ps1 evidencia    # Windows
```

Estos archivos son parte de la entrega: la tarea exige que cada caso de prueba
registre su resultado real, no solo el esperado. Por eso se versionan.
